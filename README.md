Планируемый адрес: `https://romboooo.github.io/poker-planning/`.

Папка для публикации — корень ветки `main`. В `app.js` указан API `poker-planning.fabledbull515.chatgpt.site`; для него на серверной стороне разрешён CORS только с origin `https://romboooo.github.io`.
